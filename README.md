One line of quiet, earned pride for the "One Line of Earned Pride" bounty on make.fun.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node --experimental-strip-types main.ts
cat /tmp/out/entry.txt
```

The program is deterministic: it writes the same UTF-8 line to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt`) on every run, with no clock, random source,
network call or secret. The line is 149 characters, inside the 1-240 character gate.
